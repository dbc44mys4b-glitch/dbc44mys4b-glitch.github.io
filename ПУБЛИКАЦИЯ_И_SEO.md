## 2. GitHub Pages

1. Откройте выбранный репозиторий и загрузите **РАСПАКОВАННЫЕ** файлы через Add file -> Upload files. Загрузите не ZIP, а его содержимое, прямо в корень репозитория.
2. Commit changes в ветку `main`.
3. Settings -> Pages -> Build and deployment -> Deploy from branch -> `main` -> `/(root)` -> Save.
4. Откройте главную страницу, `guides.html`, `robots.txt`, `sitemap.xml`, `family-doctor.html` и убедитесь, что они открываются без ошибки и используют правильный домен.

## 3. Google Search Console

1. Перейдите https://search.google.com/search-console/ и выберите **URL-prefix property**, введите полный адрес сайта, включая `/` и подпуть у проекта.
2. Выберите HTML file как способ проверки, скачайте файл Google и загрузите в корень репозитория. Не редактируйте имя или содержимое файла.
3. Нажмите Verify после того как файл станет доступен по URL.
4. В меню Sitemaps отправьте `sitemap.xml`.
5. В URL Inspection сначала проверьте главную и `guides.html`, при необходимости нажмите Request indexing.

## 4. Bing и AI-поиск

1. Перейдите https://www.bing.com/webmasters/ — обычно проще импортировать подтверждённый сайт из Google Search Console.
2. Отправьте `sitemap.xml`.
3. После публикации можно оповещать IndexNow о новых/изменённых страницах. Ключ уже включен в архив как `bua64a67fc121ff2e7d99d77cfc3a4d3.txt`; нужно убедиться, что файл открывается по URL корневого домена. Публикация в IndexNow не гарантирует индексацию.
4. `robots.txt` не блокирует поисковых роботов, включая OAI-SearchBot и Claude-SearchBot. `llms.txt` добавлен как вспомогательный файл — его поддержка системами не гарантируется.
