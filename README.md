# BucharestUA

Городское медиа и справочник для жителей Бухареста. [Сайт](https://dbc44mys4b-glitch.github.io/) · [Telegram](https://t.me/bucharest_info)

При ручном запуске готовим до пяти SEO-гидов и городских статей и дополнительно одну–две актуальные новости за день. Гиды и новости используют единый шаблон, проверенные источники и обложки с подтверждёнными правами.

Готовый материал отправляем владельцу на согласование. По явному согласию на конкретную версию переносим пакет выпуска в `main` одним коммитом и проверяем публичную страницу после деплоя.
