# BucharestUA

Городской справочник для жителей Бухареста и тех, кто недавно переехал. [Сайт](https://dbc44mys4b-glitch.github.io/) · [Telegram](https://t.me/bucharest_info)

## Как выходит статья

1. Готовим статью с проверенными первоисточниками, обложкой с подтверждёнными правами и ссылкой на городской чат.
2. Отправляем владельцу в чат полный предпросмотр и версию статьи. При замечаниях исправляем материал и отправляем новую версию.
3. После явного одобрения этой версии готовим один коммит и проверяем страницу после деплоя GitHub Pages.

Цель при ручном запуске — до пяти готовых статей с обложками за день. Публикации в этот день зависят от одобрения владельца.
