1. Определи конкретную аудиторию, проблему и тип поискового интента; основной запрос и 3–7 естественных смежных RU/UA запросов.

5. Подбери первоисточники; для изменяемых фактов зафиксируй дату сверки и применимость. Не выдумывай опыт сообщества, интервью, отзывы, цены, законы или сроки.

## Написание
- Начинай с конкретной ситуации, неожиданной проверенной детали или сильного, правдивого заголовка. Не используй одинаковый шаблон для всех статей.
- Форматы чередуй: городская история, маршрут, афиша, сравнение, практический разбор, локальная новость. Ориентиры: новость 150–350 слов, городская история 250–500, практический гид 400–900, сложные темы — по необходимости.
- Для практических гидов сразу после H1 дай «Коротко» из 2–4 предложений с прямым ответом. Для историй и прогулок допустим сильный журналистский лид.
- Разделы H2 отвечают на вопросы людей; первое предложение раскрывает суть. Короткие абзацы, конкретика, минимум воды. Таблицы/чек-листы/FAQ (4–8 вопросов при реальной необходимости) — только если помогают читателю.
- Пиши как компетентный дружелюбный городской журналист; объясняй румынские термины, не используй канцелярит и советы вроде «изучайте отзывы».

## SEO/GEO
- Title ориентир 45–60 символов, meta description до ~155–160, один H1, короткий латинский стабильный slug, естественные запросы без переспама.
- 2–4 реальные внутренние ссылки по смыслу, внешние первоисточники; корректные canonical, sitemap, OG, schema Article/NewsArticle. FAQPage/HowTo — только при действительном соответствии контенту; не обещай rich results.
- Самодостаточные фактические разделы, единообразные названия BucharestUA/Бухарест/Румыния/официальных органов, явные даты и определения. AI-цитирование нельзя гарантировать.
- Дата публикации и дата обновления — только реальные, не выдуманные. Полноценные RU/UA/RO/EN переводы имеют собственные URL, lang, hreflang и локализованные метаданные; отсутствующие переводы не имитировать.

## Quality Gate — обязательный
Оцени 1–10 по каждому из десяти критериев файла editorial/quality-gate.md: польза, интерес, локальная конкретика, достоверность, оригинальность, мобильное чтение, визуал/права, заголовок/анонс, SEO/GEO, повод сохранить/переслать. **Итог — минимум, а не среднее.** Каждый критерий >=8, обоснование и доказательства обязательны. Авторская самооценка не равна независимому QA PASS.
До 3 итераций доработки. Если хоть один критерий <8 или критический дефект — BLOCK, не публиковать. Норма 3–4 статьи/день не отменяет этого правила.
Независимая QA фиксирует решение и источники в editorial/qa-reviews/. Если QA недоступна, статус AWAITING_QA, не PASS.
