# BucharestUA — редакционный стандарт (2026-11-12)

**Формат:** современное городское медиа, не каталог поисковых фраз. RU/UA аудитория Бухареста; переводы RO/EN публикуются только при наличии реальных локализованных текстов.

## Приёмка
1. Заголовок обещает конкретную пользу и не искажает факты. Один ясный угол зрения и одна неочевидная деталь.
2. Ориентир 250–500 слов, короткие абзацы, без «выбирайте по отзывам» и одинаковых топ-5.
3. Даты, цены, транспортные изменения, медицинские/правовые нормы сверяются с официальным источником непосредственно перед публикацией; в статье остаётся ссылка.
4. Изображение тематически точно; Commons лицензия, источник, автор и attribution сохранены. Если нет — честная типографическая обложка; AI явно маркируется.
5. Нет ложных переводов, фиктивных интервью и отзывов. Для каждой опубликованной языковой версии нужны lang, canonical, корректные hreflang и собственный текст.
6. Страница, карточка, OG, RSS и sitemap согласованы. Проверять мобильные ширины 375/390/768 и desktop 1440 px при наличии браузерного QA; без такого теста отмечать ограничение.
7. Telegram-анонс — короткий живой тизер с URL; статус «черновик» до фактической отправки.
8. Внешние площадки: только редакционно уместные партнёрства, с проверенным URL и прозрачным статусом. Без массового спама.

## Выпуск и независимая QA
Главный редактор → журналист/фактчекер → визуальный редактор → локализация/SEO → независимая QA-функция. Критические дефекты блокируют выпуск. После публикации проверить публичный HTTP, карточки, sitemap и og:image. Нельзя считать наличие файла в GitHub доказательством публичного выпуска.

## Известные регрессии
- 2026-11-12: переходы RU/UA/RO/EN открывали закешированный старый синий лендинг. Версионировать ссылки между языками при редизайне и проверять реальный клик.
- Статья о массаже ранее получила нерелевантное военное фото: совпадения по имени файла недостаточно, требуется смысловая и визуальная проверка.

## Обязательный порог 8/10 (решение владельца 2026-11-12)

Перед выпуском применяется [Quality Gate](quality-gate.md): **минимум 8/10 по каждому из десяти критериев**, а не средний балл. Независимая QA записывает оценки, конкретные доказательства и PASS/BLOCK; любой критерий ниже 8 блокирует выпуск до переработки. Проверка фактов, тематичности изображения и авторских прав обязательна независимо от оценки. Формальный подсчёт слов/H2 не заменяет редакционную оценку. Если технический блокиратор ещё не подключён к GitHub Actions, не считать политику автоматически обеспеченной. Норма 3–4 статьи в день вторична относительно качества.
